# Ralph Progress Log
## Codebase Patterns
- Next.js App Router with file-based routing in `code-front/app/`
- Dark theme colors defined in tailwind.config.ts as `dk` (dark) and `ac` (accent) palettes
- Use `next/font` for loading Noto Sans SC (variable: `--font-noto-sans-sc`)
- Glassmorphism navbar: `bg-dk-950/80 backdrop-blur-xl`
- Background effects implemented as separate `Background` component (orbs, grid, scanline)
- Page structure: `app/page.tsx` (home), `app/estimator/page.tsx`, `app/analysis/page.tsx`
- Error boundaries must be client components (`"use client"`)
- ESLint config uses `@eslint/eslintrc` FlatCompat with `eslint.config.mjs`
- Env vars need `NEXT_PUBLIC_*` prefix for browser access
- Form validation: react-hook-form + zod v4 requires `resolver: zodResolver(schema) as Resolver<FormData>` cast when using `z.coerce`
- Toast system (`use-toast` hook + `ToastContainer` component) is reusable across all pages
- API client pattern: `AbortController` + `setTimeout` for timeout handling; clear timeout in both success and error paths
- Input focus glow: `focus:border-ac-blue focus:ring-2 focus:ring-ac-blue/20`
